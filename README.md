# regrò

The independent static website for projectregro.com. Pages and media are in `public/`. Serve this directory with a static HTTP server. Edit the HTML and CSS directly. There are no dependencies or build commands.

## Hosting

Use the Vercel “Other” preset with the repository root as the root directory. `vercel.json` sets the output directory, clean URLs and redirects from the original GoDaddy homepage, project directory and sitemap.

## Content

The nine original editorial pages were retrieved on 21 November 2026. Site images are hosted locally. Gallery images open full-size and support keyboard navigation. Five video embeds use the original Vimeo sources. The ATA initiative and territory pages are in Italian. The territory page links to the public regional and municipal documents.

The contact and newsletter request links open a visitor's email client. The old GoDaddy member accounts and subscriber list are hosted services and are outside this static website. Export any required account or mailing-list data in GoDaddy before retiring the hosting plan.
